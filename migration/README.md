# CSE291P Migration Plan

This directory contains the complete step-by-step migration plan from the mockdown codebase to a clear, pipeline-oriented structure for `cse291p`.

## Files

- `migration-plan.md` — Complete reimplementation plan with directory structure
- `stage-mapping.md` — Mapping of mockdown modules to the new pipeline stages
- `interface-contracts.md` — Public API contracts for each pipeline stage
- `milestones.md` — Implementation milestones and dependencies
- `testing-strategy.md` — Testing approach for each stage
- `configuration.md` — Options and configuration management

## Usage

1. Review the complete plan in `migration-plan.md`.
2. Follow the milestones in `milestones.md`.
3. Use `stage-mapping.md` to port each module.
4. Implement interfaces per `interface-contracts.md`.
5. Test according to `testing-strategy.md`.

This directory is gitignored and intended for planning.
